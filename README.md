## 💳 카드 추천 로직

`UserCardService#recommendCard`는 사용자의 결제 요청에 대해 가장 큰 혜택을 제공할 수 있는 카드를 추천하는 핵심 로직입니다.

### 입력값
- 사용자 ID
- 가맹점 ID
- 결제 금액

### 처리 절차

1. **혜택 필터링**  
   - 사용자와 가맹점 기준으로 적용 가능한 `Benefit` 목록을 조회합니다.
   - 조건에 맞는 카드가 없으면 대표 카드(Default Card)를 반환합니다.

2. **혜택 금액 계산 및 정렬**  
   - 각 혜택에 대한 `Discount`를 조회하고, 결제 금액 기준으로 할인 금액을 계산합니다.
   - 가장 큰 할인 금액을 기준으로 내림차순 정렬합니다.
   - 동일한 할인 금액일 경우 대표카드 여부를 우선합니다.

3. **유효성 검증**
   - 할인 조건(전월 실적 만족 여부)을 카드사 API를 통해 검증합니다.
   - 한도 조건이 있는 경우 사용 이력과 조건을 비교해 적용 가능한 할인 금액을 조정합니다.

4. **최종 추천**
   - 유효성 검증을 통과한 카드 중 가장 큰 할인 혜택을 제공하는 카드를 추천합니다.
   - 조건을 만족하는 카드가 없다면 대표카드를 반환합니다.

### 할인 방식
- `RATE`: 비율 할인 (예: 10% 할인)
- `AMOUNT`: 정액 할인 (예: 3,000원 할인)

### 유효성 검증 항목
- 전월 실적 충족 여부
- 혜택 한도 초과 여부 (일/월 횟수, 금액 제한)
- 조건별 잔여 한도 계산 및 할인 금액 조정

>  유효성 검증은 카드사 API와의 연동으로 이루어지며, 실시간 조건 충족 여부를 판단하여 신뢰도 높은 추천 결과를 보장합니다.
